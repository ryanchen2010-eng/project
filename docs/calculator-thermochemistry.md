# Thermochemistry calculator

All arithmetic is local and based on user-supplied data. Specific heat and total heat capacity assume a constant capacity over the specified temperature interval. Reaction enthalpy uses formation enthalpies and reaction entropy uses molar entropies: stoichiometric products minus reactants, per mole of reaction as written. The user must provide a balanced equation and matching species, phases, standard states and temperatures; these are not automatically verified. No data lookup, phase-change model or temperature correction is performed.

Gibbs calculations use ΔG = ΔH − TΔS with absolute temperature and unit conversion. Enter values valid for the same process and conditions. A standard-state ΔG° alone does not establish nonstandard-condition spontaneity; actual reaction quotient is not calculated. None of these results predicts reaction rate or laboratory safety.

References: [OpenStax calorimetry and enthalpy](https://openstax.org/books/chemistry-2e/pages/5-summary), [Gibbs free energy](https://openstax.org/books/chemistry-2e/pages/16-4-free-energy), and [nonstandard conditions](https://openstax.org/books/chemistry-atoms-first-2e/pages/13-4-equilibrium-calculations).
