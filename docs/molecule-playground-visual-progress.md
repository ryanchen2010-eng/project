# Molecule Playground visual progress inventory

This inventory lists accessible project and relevant temporary development images in chronological order, oldest first. The milestone column groups related work without disrupting the timeline.

**Date reliability:** A date in a filename is used as the stated screenshot date; otherwise the local file creation time is an approximation and can reflect a copy, export, or restoration. Same-day ordering is alphabetical, not a verified sequence. Descriptions are inferred from filenames and folder context unless stated otherwise; they describe what the image appears intended to document, not an independently verified code change.

**Access:** Links point to original local files; no originals were moved or modified. `/private/tmp` and clipboard files are temporary and can disappear. Review every image before sharing; beta/deployment screenshots could show private account or configuration details. Source-paper/patent page scans are excluded as references rather than website progress images.

**Changes history limitation:** Codex Changes is a change/diff view, not necessarily an archive of image files. The currently accessible files and supplied chat attachments were searched, but this inventory cannot verify every image ever shown in a past Changes view or assert that a specific unavailable image existed. Entries from chat shown without a matching accessible file should be treated as unavailable; no missing image is reconstructed.
