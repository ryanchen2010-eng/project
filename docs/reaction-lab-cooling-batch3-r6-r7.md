The named selection never supplies a measured temperature, proves completion, or generalizes to other alkenes/HX reagents.

## Scope and safeguards

The profile is explicit-only. The parent substrate and reagent identities, product, ionic model, site and existing mapped compatibility validations must all agree. Reagent, medium, temperature, added activation, version, unsupported fields, incompatible work-up and cached-identity changes fail closed. Reversed equivalent SMILES are accepted by the canonical identity. The recorded endpoint does not model excess-HCl neutralization or recovery. Guidance requires confirmation and never changes temperature. Existing geometry is a molecular conformer, not a low-temperature simulation.
