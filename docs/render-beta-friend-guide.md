Molecule Playground is a practical chemistry website for exploring molecules, drawing structures, inspecting supported reactions and calculating quantities.

## Things to try

1. Explore: search a compound by name, choose its exact structure, rotate a supported 3D model and inspect its information or measurements.
2. Builder: draw a small molecule, then use **Check + preview 3D**. Try sending the checked structure to Reaction Lab.
3. Reaction Lab: start with an existing example. Inspect 2D bond changes and, where permitted, compare the product in 3D. Select an atom to find it in both views.
4. Guided Conditions: try the existing 2-propanol oxidation guide or partial propyne hydrogenation/Lindlar guide. Read proposed replacements, confirm them, apply, and separately request 3D.
5. Calculators: try a mass-to-moles conversion, a solution calculation, or another defined calculation model. Check that changing an input clears an old result.

## What to expect

This beta supports bounded models, not arbitrary reaction prediction. A missing match does not mean a reaction is impossible. Some results are conditional 2D reporting structures only. A generated 3D conformer is not experimental proof, an isolated yield or a laboratory instruction. Some ionic compounds have information but no molecular 3D diagram. PubChem and the external 3D viewer library require working internet access.

If the free host is asleep, the first visit may take about a minute to wake. If a calculation is busy or a lookup fails, wait briefly and retry once. Send the owner the page, your non-sensitive inputs, the time, browser/device and a screenshot if something breaks. Do not send passwords, cookies or private research structures.
