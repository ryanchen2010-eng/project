# Exact-graph NIST molecular lookup

When the normal PubChem/RDKit route returns 404 for a non-ionic metal-containing PubChem record, Explorer can request a fixed-host NIST Chemistry WebBook lookup. The service gets the CID's current PubChem SMILES, full standard InChI and InChIKey, searches NIST by exact key, requires the same full InChI and key, and accepts only a unique NIST 3D-file identifier. It parses the returned SD file and requires the same complete isomeric molecular graph, including formal charge and stereochemical identity. It rejects disconnected assemblies, charged atoms, isotopic forms, radicals, invalid input, oversized structures, invalid coordinates, implausible bond distances, source mismatches and network failures. Atomic maps are removed for graph comparison only. It never infers coordination bonds from formula or adopts crystal structures. The frontend additionally checks the source graph returned by the server against the originally selected PubChem graph before rendering, guarding stale or changed records.

The model is labeled NIST-calculated, gas-phase, method and limitations; it is not labeled experimental. Only fixed PubChem and NIST hosts and a validated NIST record identifier are used; external responses have size/time bounds. The NIST file is fetched live and not bundled. Source availability, exact graph compatibility and network access are therefore required; failing those conditions preserves the existing 2D fallback. NIST 3D data are described at https://webbook.nist.gov/chemistry/3d-structs/.

Live verification: trimethylaluminum, CID 16682925, matched its exact PubChem graph and the NIST B3LYP/6-31G* model. Existing explicitly reviewed carbonyl, ZrCl4 and SF6 references remain separate and take priority; ionic assemblies remain information-only. This is a general mechanism, not a claim that all metal-containing molecules are covered or that standard InChI alone establishes coordination identity.

Update: tetraethyllead matches the full identity and graph; its computed NIST SD file does not contain a METHOD field. The resolver now accepts such records only when NIST explicitly labels the linked file computed, with method and convergence reported as unknown. The same exact-identity and coordinate safeguards apply to other eligible records. This is an isolated molecular model, not a crystal or an experimentally verified geometry.
