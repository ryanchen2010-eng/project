# Explorer xTB pilot — partial investigation

No xTB runtime or new production fallback was added. This macOS arm64 machine has no `xtb`, `conda` or `brew` command on PATH. The project's Python is 3.14.6; a binary-only `pip download --no-deps xtb` found no compatible distribution. This rules out only that installation route, not isolated conda-forge environments or building from source. The [official installation guidance](https://xtb-docs.readthedocs.io/en/latest/setup.html) describes Conda and source-build options, which have not yet been attempted here. No xTB geometries, molecular class validation, or xTB coverage gains can be claimed.

The first reproducible reference checks are in `tests/test_explorer_geometry_reference_pilot.py`. RDKit water generated O–H 0.96894/0.96907 Å and H–O–H 103.981°, versus approximately 0.958 Å and 104.5° for neutral water's cited reference in `docs/water-reference-geometry.md`. The bundled AlCl₃ reference geometry is 2.060 Å and 120.000°, consistent with [NIST's D3h geometry and 2.060 Å Al–Cl distance](https://cccbdb.nist.gov/expgeom2x.asp?casno=7446700); this is a transcription check against its own source, not independent validation of a generated AlCl₃ model. Broad water test tolerances are exploratory and cannot be extrapolated to other species.

The 32-case offline generator benchmark was rerun with 13 generated structures passing current internal graph/stereo/coordinate/convergence checks, unchanged from Step 7. This excludes live source-based reference paths and is not experimentally validated coverage. Ionic assemblies remain information-only. Twelve focused Python tests passed.

Next: establish a temporary isolated compatible xTB environment, verify executable/version and licensing, then compare multiple coordination geometries and independent references with explicit charge, spin, identity, connectivity, stereochemistry and convergence checks. Benchmark runtimes and memory under deployment constraints, and add a bounded optional adapter only after the class-specific cases pass; no local installation should become an implicit production dependency. xTB spin and transition-metal limitations mean a successful run alone is insufficient evidence of accuracy.
