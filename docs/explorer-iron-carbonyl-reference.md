# Reviewed iron pentacarbonyl reference bridge

PubChem CID 26040 returns the exact neutral fragment graph `[C]=O.[C]=O.[C]=O.[C]=O.[C]=O.[Fe]`. NIST's [iron pentacarbonyl](https://webbook.nist.gov/cgi/cbook.cgi?ID=13463-40-6) has the same named species, formula, CAS and standard InChIKey, but its calculated SD file uses explicit Fe–C single bonds and C≡O bonds. These are **not the same bond graph**; this reviewed bridge is an identity- and source-specific association, not a general claim that disconnected fragments are interchangeable with coordination complexes. PubChem CID 518773 has a different charged fragment representation and is deliberately not accepted.

The local authenticated service rechecks the exact CID and full isomeric fragment graph before fetching NIST's fixed HTTPS URL. The fetched model is bounded in size and independently screened for 11 atoms, neutral atomic charges, five single Fe–C bonds, five triple C–O bonds, plausible distances, radial ligand alignment and trigonal-bipyramidal geometry. A mismatch, unavailable source or network failure returns no reference. NIST's copyrighted file is fetched live and is not bundled; both PubChem identity and NIST availability are required. The UI labels NIST's B3LYP/6-31G* result as a calculated isolated gas-phase molecular geometry, not an experimental structure or liquid/crystal, and discloses the changed bonding representation. NIST's general [3D-method documentation](https://webbook.nist.gov/chemistry/3d-structs/) describes its calculated geometries and convergence checks.

The general validation architecture can support additional independently reviewed coordination identities and geometry-specific validators in future; it does not infer ligands, charges, spin states or structures for other substances. Ionic assemblies remain information-only. RhCl3 is not included. The frozen 16-case benchmark's synthetic invalid input remains invalid; this new reference applies to the exact live PubChem CID and its reviewed input representation, not that benchmark graph.

## Reviewed metal-carbonyl expansion

The same bounded class-specific reference mechanism additionally covers [nickel tetracarbonyl](https://webbook.nist.gov/cgi/cbook.cgi?ID=C13463393) (PubChem CID 26039; tetrahedral) and [chromium hexacarbonyl](https://webbook.nist.gov/cgi/cbook.cgi?ID=C13007926) (CID 25589; octahedral). Their exact neutral-fragment graphs and standard InChIKeys were checked against NIST; their NIST files were independently fetched and validated against the appropriate coordination geometry. Each requires the exact reviewed CID and fragment representation, a live NIST response, metal and ligand counts, connectivity, distances and shape; arbitrary carbonyls, different charges, isotopes, other CIDs and other geometries are not inferred. These are calculated isolated gas-phase structures and are not automatically experimental or condensed-phase structures.
